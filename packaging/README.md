# Mosaic Desktop · V0.8.15

Windows 11 x64 + .NET 10 Desktop Runtime；双击 Mosaic.exe。

V0.8.15 新增 GPT、Gemini、Claude、Qwen 的正常比例版本，保留所有 Q 版和 DeepSeek 正常版。设置 → 桌宠 → 选择角色中选带「正常比例」的名字后保存；默认高度为 Q 版的两倍，可独立调节。新增四位均配齐 29 个缓存姿态，保留专属动作、悬停和随机聊天，以及最多五开。共 11 款角色、319 姿态，详情和图片见 NORMAL_PET_VARIANTS.md。发行清理遇到仍在运行的旧版时，保留其目录和 ZIP，退出后下次发布再清理。

V0.8.14：单按 Win 同时显示并保持 Dock 与顶部菜单，再按一次收起。发布目录只保留最新版。

V0.8.13：鼠标在角色有色区域停留约 0.25 秒，随机播放摸头或挥手；单击也能播放相同动作，并随机说一句符合人设的话。已有悬停动作时接着说话，不重新起帧。五套性格各 20 句，共 100 句，含陪伴和互相吐槽，连续点击不会重复上一句。原版与两种 DeepSeek 共用鲸鱼性格。气泡约 4.5 秒，可在桌宠设置中关闭；随机台词完整列表见 PET_CHAT_LINES.md。设置预览和右键菜单也可以「聊一句」。

V0.8.12 新增 GPT 白龙娘、Gemini 星猫娘、Claude 书卷娘、Qwen 折扇娘，保留原版与两款 DeepSeek。七款角色各有 29 个缓存姿态；新增角色分别有龙翼舒展、猫爪比心、翻一页书和开合折扇，问候、投喂、疲惫、求 token 等台词各自独立。

设置 → 桌宠 →「启用桌宠陪伴」，在「同伴名册」点击「添加一位」，为每位选择角色后保存。最多保留 5 位（主位加 4 位同伴），可重复选择同一角色。每位的位置、大小、反应与全屏隐藏偏好独立；右键「收起这位伙伴」只收起当前一位。托盘总开关控制所有伙伴。旧配置自动保留原来的单桌宠。

继续使用正常→过渡→最终表情的关键帧，不使用 GIF、变形或动态粒子；走路保持移除，全部原图保留，DeepSeek 正常比例维持两倍尺寸。完整台词见 AI_PET_PERSONALITIES.md，动作与关键帧图见 PET_EXPRESSIONS.md。升级先退出旧实例，再运行新版。

V0.8.5 将 DeepSeek 正常比例版的桌面显示高度和宽度等比放大到 V0.8.4 的两倍，默认画布 440 × 440 DIP；两款 Q 版大小保持原样。原有大小设置继续生效，正常比例版的大小标签显示加倍后的尺寸。

V0.8.4 新增 DeepSeek Q 版与正常比例版桌宠，保留原版鲸鱼娘。组件 →「领养与动作预览」→「选择桌宠」，勾选启用后保存；每款都有 20 个姿态，含摸头、喂饭、打字与头顶饭盆。正常比例指人物身材比例，显示大小仍可单独调整。一次选择一位伙伴，旧配置继续使用原版。`--pet` 可直接开启桌宠与设置。

新桌宠参考 SelinLee / AI Moe Atlas 的 DeepSeek v5 派生设定图；社区角色设计：上善无形 → ZipZipPipe。素材由内置 image_gen 重新生成，沿用参考的 CC BY-NC-SA 4.0 条件；素材署名见 licenses/DeepSeek-Pets-NOTICE.md，代码许可不变。

V0.8.3 修复 V0.8.2 顶部菜单停在极小高度、界面无响应的问题，保留菜单占位与平滑过渡。

主界面为设置与插件管理，支持拖动边缘或右下角缩放。开启覆盖不会再将管理窗口铺满桌面。
时钟、笔记、待办、CPU、内存、网络、存储和快捷访问由同一块桌面画布承载，固定在 Explorer 桌面层，普通应用自然覆盖它们。
控件默认锁定，没有标题栏、关闭按钮和缩放边框。通过插件管理或顶部菜单进入“编辑桌面布局”，再移动或缩放；点击“完成”保存，“取消”或 Escape 恢复。插件开关放在管理窗口内。
Dock 与顶部菜单栏：返回桌面或没有可见的最大化/全屏应用时，保持显示；其他情况下才按各自自动隐藏设置收起。移到屏幕顶边或主屏底边可呼出，移开约 0.8 秒后收起，菜单使用期间保持展开。设置中可关闭自动隐藏，使其始终显示。顶部菜单展开时始终预留 32 DIP 工作区（随屏幕缩放），已有最大化窗口同步下移，避免遮挡标题栏与关闭按钮；收起后释放空间，各屏幕独立处理。
Dock 设置支持 24–80 图标大小，直接读取应用图标，不带快捷方式箭头。
自动隐藏时移动到主屏底边中央呼出；运行中的应用实时加入，点击切换窗口。
最大化应用使用更新后的屏幕工作区；Dock 呼出时显示在应用上方。
V0.8.2：顶部菜单展开约 280ms、收起约 220ms，滑动与实际工作区高度同步缓动；中途唤回从当前位置反向。设置 → 外观 →「界面过渡与渐变动画」控制该效果，关闭后立即切换。
关闭管理窗口后，桌面组件继续工作。覆盖期间有一个无窗口恢复进程，负责异常退出后的任务栏和工作区恢复。

Ctrl+Alt+M：切换 Mosaic / Windows。
Ctrl+Alt+D：打开插件管理。
Ctrl+Alt+Space：全局搜索。
Mosaic 桌面模式下，单按左／右 Win 同时展开 Dock 和所有屏幕的顶部菜单，并保持显示，鼠标移开不会自动隐藏；再次单按 Win 收起，之后仍可从屏幕边缘唤出。长按只在松开时切换一次。Win+D、Win+E 等组合键保留，Ctrl+Esc 继续拦截开始菜单。切回 Windows 或退出后解除拦截；该显示状态不写入配置。
退出 Mosaic：顶部 MOSAIC 菜单或托盘。

配置位于 %LOCALAPPDATA%\Mosaic；不移动或删除原文件，不修改 Windows 固定应用。
当前控件画布覆盖主屏；多屏布置和 Explorer 重启等场景仍需扩展验收。
--overlay：开启覆盖；--dashboard：打开管理；--exit：保存后退出；--data-dir <目录>：隔离配置。


V0.8：设置 → 外观可组合五种主题与五种强调色，并分别开关透明质感、渐变与淡入动画；设置 → 快捷键可录入六组全局快捷键。
桌面组件新增 GPU、显存、温度和风扇 RPM。NVIDIA GPU 温度可直接读取驱动；CPU/主板温度及 RPM 取决于硬件接口或已运行的 Libre / Open Hardware Monitor WMI 提供者。不可用时显示 — 和原因，不安装驱动或自动提权。
工作空间现在分别保存桌面组件布局；笔记与待办共享。桌面编辑支持网格、撤销/重做、恢复默认和方向键微调。

顶部右侧提供输入语言、网络、音量和电池状态；点击时间打开日历，主屏的「⌃」展开真实后台托盘图标，支持左右键与双击。面板或菜单打开时保持顶部栏展开。
