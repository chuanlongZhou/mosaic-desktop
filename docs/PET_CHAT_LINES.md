# 桌宠随机聊天 · V0.8.15

鼠标在角色有色区域停留约 0.25 秒，播放一次摸头或挥手动作；单击触发同类动作，同时随机说一句话。点击已有悬停动作时不重置动画阶段。每位连续点击不会重复上一句，气泡保持约 4.5 秒，关闭「显示心情气泡」后隐藏文字。设置预览的「随机聊一句」和右键的「聊一句」也使用这些内容。

共五套性格、100 句。原版鲸鱼娘与两款 DeepSeek 共用鲸鱼性格，四位 AI 娘各有独立内容，同一角色的 Q 版和正常比例版共用该套台词。以下是本项目原创桌宠台词，吐槽围绕角色习惯和道具设计。所有内容本地预置，不调用在线模型。
