## V0.2 · Command Palette 与本地搜索

2026-10-22。按 V2.1 继续扩展现有四个项目，保留原生 WPF、一个主进程和 JSON 存储。当前是开发预览，不代表完整 V0.2 性能及兼容性验收完成。

### 已实现

- 全局 Ctrl+Alt+Space、可变更快捷键与注册冲突提示；工作台 Ctrl+K、侧栏、Dock 和托盘接入统一 Command Palette。窗口按需创建并复用，隐藏时取消查询、清空结果视图，30 秒后释放文件热索引。
- 应用发现：用户和公共开始菜单、Windows AppsFolder、内置应用；独立 STA 后台线程执行 COM 发现，仍在同一进程内。应用目录在会话内缓存。
- 文件范围由用户明确选择，默认无目录；最多 8 个本机具体目录。排除 Windows、Mosaic 数据目录及父目录、系统/链接/云占位资源和常见构建缓存。仅采集名称、路径、类型、大小、修改时间。
- 热索引最多 20,000 项 / 估算 32 MiB；100 MiB 总磁盘预算，按目录与索引代组织 JSONL 块。manifest 切换后才发布新索引，取消保留上一代；冷搜索默认 1 秒，继续搜索延长至 8 秒，部分覆盖明确提示。
- FileSystemWatcher 变更在 3 秒内合并；扫描并发为 1，扫描期间的变更合并为下一次刷新，监听溢出重扫。睡眠取消扫描，唤醒后刷新。
- 查询规范化、80 ms 防抖、中文组合输入抑制、旧查询取消与世代检查、按来源渐进结果、路径去重、稳定排序、类型筛选、前 50 项虚拟化列表和按选中加载详情。匹配和索引读取在工作线程执行。
- 收藏与标签保存到 64 个 JSON 资源分片；普通文件不会因索引而自动注册资源。第一次收藏、加标签或固定 Dock 时分配稳定 ID。Dock 关联同一 ID，最近成功打开的资源最多 30 项，不保存输入的搜索词。
- 打开、定位、复制路径、收藏/取消、编辑标签、固定 Dock 复用命令注册表。固定 Dock 的退出等待覆盖资源分片与设置两次保存，避免退出时漏掉后一次写入。
- Everything 使用既有消息窗口上的 Unicode WM_COPYDATA 协议；可选连接经典默认实例，缺失/未就绪/超时降级。默认与选择目录同范围，显式开关才可扩大到其全部磁盘索引。候选最多 200 项后本地排序；无需 SDK DLL、额外搜索进程或安装动作。
- V0.1 JSON 通过新增字段兼容读取；不重置原 Dock、主题、笔记或待办。新用户默认 Dock 带搜索，旧用户可在“+”菜单添加。

## V0.1 基础桌面预览（历史记录）

2026-10-22，按 V2.1 的轻量化方案开始实现。当前交付覆盖工程骨架、桌面时钟、Dock、Dashboard、必要设置与 JSON 存储；不将其视为 V2.1 全产品或 V0.1 正式验收完成。

## 已落地的技术约束

- 四个生产项目，普通 C# 接口与手动装配，没有 Web 界面运行时、数据库、ORM、DI 容器或后台服务。
- 默认一个 Mosaic 进程；工作台按需创建并在关闭后释放。后台监控依附工作台可见状态，不启用文件扫描。
- 内置 `System.Text.Json` 源生成；JSON 文档最多 1 MiB，笔记 20,000 字符，任务 200 项，Dock 24 项。
- 单个串行写入门禁，最多 32 个排队请求。保存前校验结构、revision 与文件指纹；同目录写临时文件、刷新、替换并保留 `.bak`。
- 只在最后成功提交后更新内存 revision；恢复过程先校验备份并保留异常文件，未来 schema 不进行静默迁移。
- Dashboard 的 12/8/4 列独立布局、碰撞重排和会话 20 步撤销；默认 8 个组件，无无限滚动数据源。
- 系统采样使用公开 Win32 和 .NET 接口；折线最多 60 点，无图表包。时钟按分钟更新。
- 明确资源命令注册表，文件打开校验存在性；未注册命令不能进入执行逻辑。

`scripts/test.ps1` 覆盖默认配置往返、三个断点 750 次布局移动、备份 revision、截断 JSON 恢复、未知版本恢复、不可恢复文件保留、外部修改冲突、并发过期写入、内容与路径边界、未注册命令以及取消保存。
