# V0.8／V0.8.1 外观、快捷键、监控与托盘

当前版本：V0.8.1，2026-10-24。本指南汇总 V0.7 之后新增的功能；旧配置继续迁移，组件布局按工作空间保存，笔记与待办继续共享。

## 顶部状态、日历与系统托盘

- 顶部右侧集中显示日期时间、输入语言、网络、音量和电池状态；没有电池的设备隐藏电池项，没有音频输出设备时说明不可用。
- 点击时间打开日历；输入语言菜单切换当前应用的键盘布局；网络、音量和电池按钮打开对应 Windows 设置，当前不提供内置音量滑块。
- 主屏通过「⌃」展开后台应用的真实托盘图标，支持左键、右键、双击与键盘激活，以及图标的新增、更新和移除。应用需响应 `TaskbarCreated` 才能重新登记已有图标。
- 使用托盘面板、日历或原生右键菜单时，顶部菜单保持展开。切回 Windows 或退出时释放托盘服务；异常退出时恢复保护会重新广播图标登记消息。
- WPF 右键菜单与子菜单，以及 Mosaic 自身的 WinForms 托盘菜单使用统一深色样式。

托盘使用固定版本 `ManagedShell 0.0.374`。首次源码构建需要联网还原依赖，运行包携带相应组件和 [Apache-2.0 许可证](../packaging/licenses/ManagedShell-LICENSE.txt)，不直接搬动 Explorer 的通知区域窗口。

## V0.8.1 顶部菜单与应用窗口

回到桌面或没有最大化应用时，Dock 与顶部菜单保持展开；其他场景沿用各自自动隐藏设置。与 V0.7 相比，顶部菜单现在每次展开都会预留 32 DIP 的工作区，包括边缘临时唤出；最大化窗口位于菜单下方，收起后释放空间。各屏幕独立维护可见状态，周期工作区维护不会清除已经展开的占位。

Dock 保留原有底边唤出行为；上述更新是顶部菜单的占位规则，不改变单按 Win 的开始菜单拦截和 Win+D 等组合键。

## 外观

设置中心 → 设置 → 外观，提供 5 种基础主题与 5 种强调色，可自由组合。

- 基础主题：午夜蓝、石墨灰、森林绿、暮光紫、晨光浅色。
- 强调色：天空蓝、薄荷绿、鸢尾紫、玫瑰粉、琥珀金。
- 透明质感：独立开关，表面不透明度 65%–100%；关闭时使用实色。桌面组件和 Dock 使用透明表面；原生窗口在系统支持时使用 Windows 11 Mica 背景材质，失败时回退实色。
- 动画：独立开关，控制页面淡入、主题颜色过渡和按钮悬停渐变；关闭后立即停止。系统关闭动画时不强制开启动画。
- 选择主题与强调色立即预览。保存后写入当前配置；取消恢复已保存外观。关闭有未保存修改的抽屉时询问保存或放弃。

主题是当前配置的全局外观；工作空间分别保存桌面组件布局、Dock 和资源入口。

## 默认快捷键

| 操作 | 默认值 |
| --- | --- |
| 切换 Mosaic / Windows | Ctrl+Alt+M |
| 打开设置中心 | Ctrl+Alt+D |
| 全局搜索 | Ctrl+Alt+Space |
| 打开资源库 | Ctrl+Alt+L |
| 打开工作空间 | Ctrl+Alt+W |
| 编辑桌面布局 | Ctrl+Alt+G |

设置 → 快捷键，点击输入框并按组合键。Backspace / Delete 清除绑定，Tab 切换输入框，可一键恢复默认。

保存前检查应用内部重复及系统占用。新绑定先保留，配置写入成功后才交接；失败或取消会释放新绑定，保留原绑定。录入已有 Mosaic 快捷键时只录入，不触发对应操作。清除搜索快捷键不关闭搜索功能，仍能从按钮进入。

## 监控数据

| 项目 | 来源与显示方式 |
| --- | --- |
| CPU | Windows 系统总使用率，约每 2 秒更新 |
| 内存 | Windows 物理内存使用比例、已用与总量 |
| GPU | NVIDIA NVML 优先，显示所选最忙 NVIDIA GPU 名称；其他驱动使用 Windows GPU 引擎计数器，按物理引擎合并进程后取最忙引擎 |
| 显存 | NVIDIA 显示对应 GPU 专用显存已用/总量；Windows 计数器回退显示适配器专用显存合计 |
| 温度 | NVIDIA GPU 核心、可用 ACPI 热区，或 Libre / Open Hardware Monitor 的本机 WMI 传感器；显示最高读数并在提示中列出来源 |
| 风扇 | Libre / Open Hardware Monitor WMI 的 Fan 类型读数，单位 RPM；不把风扇百分比转换成 RPM |
| 网络与存储 | 当前连接上传/下载速率，系统磁盘占用 |

硬件监控不安装驱动、不自动提权。CPU/主板传感器和风扇 RPM 能否读取由设备、驱动和已运行的传感器提供者决定。没有数据时显示“—”与原因；ACPI 热区不标成 CPU 核心温度。

GPU 原生计数器与基础采样约每 2 秒更新；可用的 WMI 传感器后台缓存约每 5 秒更新，无接口时约 30 秒后重试。温度与风扇详情可通过悬停读数查看。

## 交互与迁移

- V0.8.1：顶部菜单展开时占用 32 DIP 的屏幕工作区（随缩放调整），包括边缘唤出；最大化窗口同步下移，不覆盖标题栏和关闭按钮。菜单收起释放空间，各屏幕独立维护占位；正常退出或异常终止后恢复 Windows 原工作区。
- 组件管理使用随窗口宽度调整的卡片和只读内容预览。预览不会接收笔记、待办或快捷访问的编辑输入。
- 设置抽屉禁用底层内容，Tab 留在抽屉内；关闭后恢复入口焦点。
- 笔记和待办在桌面显示保存状态、错误与重试，不因系统指标更新而清除保存失败提示。
- 待办可编辑、隐藏已完成、撤销最近一次删除。
- 编辑桌面布局支持 12 DIP 网格、撤销/重做、恢复默认和方向键移动；Shift+方向键每次移动 10 DIP。取消拖动后不再吸附或提交已取消的布局。
- 每个工作空间分别保存桌面组件的启用状态、位置和大小；笔记与待办共享。旧工作空间首次切换前保存当前布局，缺少的新组件以关闭状态补齐。
- 资源库支持拖入登记、Enter 打开、Ctrl+C 复制路径；无选中资源时隐藏详情，宽窗口也可手动收起。
