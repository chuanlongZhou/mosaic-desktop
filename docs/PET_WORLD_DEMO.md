# 图书馆茶室：五位 AI 娘的 2.5D 场景演示

独立 WPF 演示项目：`src/Mosaic.PetWorldDemo/`。复用当前五位正常比例角色和生产版 `WhalePetSprite` 的全部素材，不修改原来的置顶桌宠、设置和桌面接管逻辑。

## 启动

直接运行 `output/pet-world-demo/app/Mosaic.PetWorldDemo.exe`，或运行 `scripts/run-pet-world-demo.ps1` 构建并启动。使用现有 .NET 10 Desktop Runtime；本机已通过运行验证。该项目可以单独构建，不需要把主应用切换到 Mosaic 桌面。

这是窗口 / 沉浸场景 demo。沉浸预览是普通的全屏窗口，没有置顶；尚未挂载到 Windows 壁纸层，不改变系统壁纸、桌面图标、任务栏或现有宠物配置。

## 场景与人物

- 等距投影的剖面茶室：两面墙、窗景、双书架、书桌、茶台、茶点小桌、地毯、五块休息坐垫和植物。
- 角色、家具按深度排序；人物使用统一脚底锚点和轻微远近缩放。
- DeepSeek 爱吃饭，以饭碗验证一切；GPT 习惯列提纲，但愿意自嘲；Gemini 想法活泼，也会接受朋友的提醒；Claude 安静、认真，吐槽藏在批注里；Qwen 负责把大家的长话收成短句。
- 场景台词全部为本地原创预置剧情，与角色既有性格台词衔接。不会调用模型 API 或读取实际 token 额度。

## 六章、48 幕，正常速度约 5 分 32 秒

| --- | --- | --- |

| 共写 · 一页就好 | 五人合写一页 → DeepSeek 加开饭备注 → Qwen 抓住重点 → Gemini 在页边加星星 → GPT 帮忙整理 | 左右打字、专属动作、鼓脸、共同欢呼 |

每幕只有一位发言者，其余角色做与当前情境相符的动作。后一句回应前一句，切换活动区时先等角色到位再开启台词。剧本结束后循环。

## 动作覆盖

每位 29 个姿态，其中 27 个在整轮剧情中自动出现。摸头 `Pat` 通过“摸摸头”或双击角色触发；拎起 `Drag` 只在用户实际拖动角色时触发。五位合计 145 个姿态。

通用内部姿态名 `RiceHat` / `RiceHatTilt` 在各角色处映射为自己的专属动作：DeepSeek 顶饭碗、GPT 展龙翼、Gemini 猫爪比心、Claude 翻书、Qwen 开合扇。

现有角色没有可用的统一步行循环，导航阶段是保持身体比例的短距离平移，不冒充新增步行动画。完整行走、转身和坐到椅子上的动作应在后续素材阶段补齐。

## 操作

- 选中右侧角色，或单击场景中的角色；双击角色摸头。
- 按住角色有色区域拖动，进入拎起姿态；松手后落在最近的合法空地，避开家具和其他角色。
- “摸摸头”“递茶点”“打个招呼”“一枚纸 token”临时中断剧本，随后恢复；不会同时堆叠两个对白。
- 空格暂停 / 继续；右方向键下一幕；下拉菜单跳到指定章节；支持 1× / 2× / 4×。
- “沉浸预览”隐藏控制区，Esc 返回；最小化后停止模拟和绘制，返回时不追赶堆积的帧。

## 导航与验证

世界坐标中维护家具占用、0.5 单位寻路网格和角色脚底位置。寻路检查线段是否穿越家具；移动时保持角色间距，短暂受阻后避开同伴重新寻路。中途重新寻路从实际位置选择可达的网格入口，避免两位角色在网格之间互相堵住。

运行：

```powershell
& .\output\pet-world-demo\app\Mosaic.PetWorldDemo.exe --verify .\output\pet-world-demo\verification
```

验证完整 48 幕不卡住、家具避让、角色间距、27 自动 / 29 完整姿态、暂停、主动互动优先级、拖动落点、章节重置、倍速、145 幅生产素材，以及六章实际 WPF 渲染和窗口初始布局。报告位于 `output/pet-world-demo/verification/verification.json`。
