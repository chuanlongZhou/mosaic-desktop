# Mosaic Desktop · V0.5 桌面插件与设置中心

2026-10-24：主界面改为可自由缩放的设置与插件管理窗口，开启覆盖模式不会再强制全屏，也不会自动打开管理窗口。

- **内置桌面插件**：时钟、随手记、待办、CPU、内存、网络、存储、快捷访问。可独立开关、拖动标题栏移动、拖动右下角改变大小。位置、尺寸和内容自动保存；关闭管理窗口后继续工作。笔记和待办复用同一个数据模型，避免多窗口覆盖写入。
- **常驻时间**：屏幕顶部菜单栏显示日期和秒钟，管理窗口和 Dock 也显示时间。顶部提供插件管理、搜索、资源库、工作空间、切回 Windows 和退出入口。
- **可调 Dock**：在设置中将图标大小调整至 24–80 后保存；保持任务栏固定项导入、运行窗口合并及自动隐藏。快捷方式直接提取原始图标资源，不带快捷方式箭头；不修改系统图标或原快捷方式。
- **窗口与最大化**：覆盖时重新设置每块屏幕的工作区，为顶部时间栏预留空间；Dock 关闭自动隐藏时，在主屏额外为它预留空间。最大化窗口匹配新工作区，自动隐藏的 Dock 在底边呼出时保持在其他应用上方。切回 Windows、正常退出或主进程异常终止时恢复原工作区。
- 覆盖模式保留原壁纸，隐藏 Windows 任务栏和桌面图标；设置窗口、资源库和工作空间按需打开。Ctrl+Alt+M 切换桌面；Ctrl+Alt+D 打开插件管理。

运行包：`artifacts/Mosaic-v0.5-win-x64/Mosaic.exe`。`--overlay` 开启桌面覆盖；`--dashboard` 另外打开管理窗口。源码运行使用 `scripts/run.ps1`。

验证包含管理窗口在覆盖模式下可缩放、桌面插件尺寸持久化、关闭管理窗口后笔记继续保存、Dock 尺寸设置、真实最大化窗口工作区与 Dock 置顶，以及正常退出/强制结束后的任务栏与工作区恢复。更多多屏设备、Explorer 重启、游戏独占全屏和长时间驻留仍待扩展验收。插件目前为内置组件，不提供第三方代码插件加载。

# Mosaic Desktop · V0.4 覆盖桌面预览

2026-10-24：新增可切换的 Mosaic 覆盖桌面和应用 Dock。

- 工作台右上角「启用 Mosaic 桌面 / 切回 Windows」、托盘菜单或 **Ctrl+Alt+M** 切换。Windows 模式不显示 Mosaic Dock 和桌面时钟；覆盖模式隐藏 Windows 任务栏与桌面图标，在桌面层显示 Mosaic 背景，外部应用仍可正常使用。
- Dock 自动读取用户任务栏固定快捷方式，并从任务栏记录补充商店应用；只读取，不改动 Windows 固定项。优先采用可读取的原顺序；无法匹配的快捷方式作为补充项。每 20 秒刷新固定项。
- 每 2 秒更新可见应用窗口。已固定应用合并运行状态，未固定应用显示临时入口；关闭最后一个窗口后移除。图标下圆点表示运行中，点击激活或恢复窗口，右键可选择运行窗口。受权限限制或特殊宿主的窗口可能无法识别。
- Dock 默认自动隐藏，移到主屏幕底边中央呼出，移开约 800 ms 后隐藏。应用较多时可在 Dock 上滚轮横向浏览。设置中可关闭自动隐藏或任务栏同步。
- 正常退出会恢复 Windows 桌面。覆盖期间另有一个不显示窗口的 Mosaic 恢复进程；主进程被强制结束后恢复任务栏和桌面图标，不结束 Explorer，不改注册表 Shell 或任务栏固定配置。
- 外接屏幕变化、Explorer 重启和长时间驻留仍需扩展验收；Dock 当前在主屏幕显示。

运行：`.\scripts\run.ps1 -Dashboard`；发行目录 `artifacts/Mosaic-v0.4-win-x64/Mosaic.exe`。首次开启覆盖预览也可传 `--overlay --dashboard`。已有配置的自动隐藏选项保留，可在设置中更改。

自动检查新增固定项读取、去重、真实新窗口出现和关闭、正常退出与强制终止后的任务栏恢复。完整资源库、工作空间和存储功能见下面的 V0.3 说明。

# Mosaic Desktop · V0.3 第一阶段开发预览

按照 [V2.1 实施文档](Mosaic_Desktop_项目实施文档_V2.1.md) 继续实现 Resource Library 和基础工作空间切换。原生 C# / .NET 10 / WPF，一个 Mosaic 主进程；配置、收藏、标签、集合和工作空间使用 JSON，文件索引使用可重建 JSONL。没有数据库、浏览器运行时、后台服务或第三方 NuGet 运行依赖。

## 本轮交付

- **统一工作台**：Dashboard、资源库、工作空间共用同一个窗口和侧栏；首次进入才创建对应页面，关闭工作台后释放视图、预览与采样器。进入资源库或工作空间页时停止 Dashboard 监控采样。
- **Resource Library**：卡片 / 列表、类型和标签筛选、名称 / 路径搜索、收藏、集合、工作空间资源导航。只管理已经登记的资源，不把扫描发现的所有文件复制进元数据。
- **添加与操作**：添加文件、文件夹、项目目录；打开、定位、复制路径、收藏、编辑标签、加入集合 / 工作空间和固定 Dock。模型默认定位文件，不默认加载权重。
- **多选**：Ctrl / Shift 选择当前页的多个资源，统一收藏、保存标签或管理集合成员。批量保存标签会使用标签框内的完整列表；各项依次提交，失败保留已经成功的写入并报告。
- **三类集合**：普通集合保存成员 ID；智能集合按类型、标签、完整目录和关键词进行 AND / OR 匹配；项目集合聚合目录下已登记资源及手动关联的应用、模型。集合规则不运行代码，也不扫描新目录。
- **基础预览**：选中后显示可用状态、路径、大小、修改时间；部分文本格式最多预览 2,048 字符，PNG / JPEG / BMP 在 16 MiB 文件上限内解码为受限尺寸。网络路径、链接、离线和云占位资源不自动读取正文。
- **基础工作空间**：克隆当前环境，或创建 AI Lab / Writing 预设；重命名与切换。分别保存 Dashboard 布局、Dock 和资源 ID 引用，切换前保存当前状态。Dashboard 快捷访问显示前 4 个资源入口，资源库可查看全部。
- **搜索复用**：收藏、标签、资源 ID、最近使用和资源操作与 Command Palette 共用；搜索中可“加入当前工作空间”或“在资源库整理”，也可直接搜索工作空间名称执行切换。

这是 V0.3 的资源与基础工作空间切片，尚未覆盖完整 MVP：快捷设置、统一 Studio、Light / Minimal 主题、应用自动启动及第三方窗口恢复留给后续阶段。当前工作空间主题仍为 Dark。Mosaic 工作空间不等于 Windows 虚拟桌面；切换不启动或关闭外部应用。笔记与待办在各工作空间之间共享。

## 运行与日常使用

环境：Windows 11 x64 + .NET 10 Desktop Runtime；开发另需 .NET 10 SDK。当前工作区已准备好独立 SDK。

```powershell
.\scripts\run.ps1 -Library
.\scripts\run.ps1 -Workspaces
.\scripts\run.ps1 -Palette
.\scripts\run.ps1 -Dashboard

# 隔离配置试用
.\scripts\run.ps1 -Library -DataDirectory .\.artifacts\my-preview-data

# 等待保存后退出当前数据目录对应的实例
.\scripts\run.ps1 -Exit
```

也可双击发行目录 `artifacts\Mosaic-v0.3-win-x64\Mosaic.exe`。首次运行显示工作台；以后按设置保持轻量桌面。侧栏进入“资源库”或“工作空间”，托盘和 Dock 的“+”菜单也提供入口。关闭工作台保留 Dock 与托盘，完全退出使用托盘“退出 Mosaic”。同一数据目录再次启动只通知已有实例；不同数据目录用于开发隔离。

- Ctrl+Alt+Space：全局搜索；工作台内 Ctrl+K 也可呼出。
- Ctrl+Alt+D：打开 Dashboard。
- 搜索窗口：方向键选择，Enter 执行，Tab 进入操作，Esc 关闭。
- 程序参数：--library、--workspaces、--palette、--dashboard、--exit、--data-dir <目录>。

建议先完成这条使用流程：

1. 在全局搜索右上角齿轮选择文件搜索目录，保存后建立索引；默认不扫描任何目录。
2. 搜索资源并收藏，或在资源库“添加资源”。已有 V0.2 收藏和标签会直接显示。
3. 新建“AI Models”集合，把资源加入集合；在工作空间页创建 AI Lab / Writing，再把资源入口加入相应工作空间。
4. 切换工作空间，查看 Dashboard 布局、快捷访问和 Dock；通过“查看此工作空间的资源”进入完整列表。

原有 V0.1 / V0.2 JSON 可读取，旧 Dock 不会被重置。新用户默认 Dock 带资源库与工作空间入口；旧用户可在“+”菜单自行添加。布局编辑期间须先保存或取消，再切换工作空间，避免丢弃草稿。资源库和工作空间入口可在模块设置中独立隐藏，用户元数据继续保留。

## 搜索与轻量化边界

| 项目 | 当前实现 |
| --- | --- |
| 窗口与进程 | 一个主进程，原生 WPF；资源库与工作空间嵌入原工作台 |
| 查询 | 80 ms 搜索防抖、中文组合输入抑制、取消旧查询、丢弃过期结果；资源库筛选为 100 ms 防抖 |
| 搜索结果 | 固定来源合并与去重，最多显示 50 项；开始菜单和 Windows AppsFolder 应用发现会话内缓存 |
| 本地索引 | 最多 8 个具体本机目录；不扫描整盘、UNC、Windows 或 Mosaic 数据目录及其父目录，不读取正文 |
| 索引预算 | 热索引最多 20,000 条 / 估算 32 MiB，隐藏搜索 30 秒后释放热数组；磁盘缓存总预算 100 MiB |
| 缓存与更新 | 每块最多 2,000 行 / 2 MiB；manifest 按代切换，取消保留旧代；变更 3 秒合并，单次扫描 |
| 大目录搜索 | 冷搜索通常最多 1 秒，继续搜索重新查询并延长到 8 秒；超时或预算不足标明部分覆盖 |
| 登记资源 | 64 个 JSON 分片，最多 10,000 项 / 估算 32 MiB；同一资源跨入口使用同一 ID |
| 资源库界面 | 卡片每页 36 项；列表每页 100 项并虚拟化；筛选覆盖全部已载入元数据 |
| 集合与工作空间 | 集合最多 200 个 / 8 MiB；工作空间目录读取最多 100 个 / 16 MiB，仅缓存摘要 |
| 预览 | 一个选中资源、一个预览任务；图片解码最多 256 × 180，离开页面取消预览 |

条目预算不等于进程总内存。冷搜索在逐行边界检查超时，无法保证操作系统的每次磁盘读取都在时限内完成。超大配置保留原文件并报告读取或写入限制，不自动引入数据库。新装应用可重启 Mosaic 刷新发现目录。

Everything 通过 Windows IPC 可选连接已运行的经典 1.4 默认实例，不安装服务、不分发 SDK DLL。默认限于选择目录，显式勾选后才允许它的全盘索引范围；缺失、未就绪或超时均保留本地搜索。每次最多 200 个候选再本地排序，不宣称完整的全盘最优排名。命名实例、1.5 Alpha 和本机在线端到端连接仍需后续验收。[官方 SDK / IPC](https://www.voidtools.com/support/everything/sdk/)

## JSON 与切换恢复

默认 `%LOCALAPPDATA%\Mosaic`：

```text
active-profile.json
profiles/default/
  settings.json                    模块、当前工作空间、当前 Dock、搜索和资源库视图
  workspaces/<id>.json              名称、Dark 主题、布局、Dock 快照、resourceIds
  resources/00.json … 3f.json        稳定资源 ID、类型、路径、收藏与字符串标签
  collections/<id>.json             集合类型、资源引用、受限匹配规则
  workspace-switch.json             最近一次切换的执行 ID、阶段、源与目标
  recent.json                       最近成功使用的 30 项，不保存输入的搜索词
  widget-data/local-content.json    共享笔记与待办
cache/index/<root-hash>/
  manifest.json
  <generation>/chunk-0000.jsonl     可重建文件元数据
logs/startup.jsonl                   有容量限制的启动故障记录
```

用户 JSON 保持 camelCase、schemaVersion 与递增 revision。保存使用原来的单写队列、结构校验、同目录临时文件、安全替换和 .bak；运行中的外部修改会触发冲突保护。手动编辑配置前请先退出。升级兼容读取旧数据，跨版本回退写入尚未验收。

基础切换按 Preflight → Snapshot → ApplyMosaicState → Complete 执行。先验证目标并保存源工作空间，再提交 settings.json 中的当前指针与目标 Dock，最后更新内存与界面。指针写入失败继续使用源空间；指针已提交而后续步骤失败时报告部分完成，重启以最后成功指针恢复。取消仅在提交开始前生效。没有跨文档数据库事务。

添加集合或工作空间引用前先登记资源；第二步失败允许保留未引用的元数据，避免创建悬空引用。移除集合成员、工作空间入口、收藏或 Dock 项不会移动或删除原文件。项目集合按目录自动匹配的项，须调整目录规则才能排除。文件移动或离线后保留原元数据，本轮不自动推断新路径。
